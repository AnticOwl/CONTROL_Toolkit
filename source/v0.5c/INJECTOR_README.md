# CONTROL Toolkit v0.5c — Injector

1. Start CONTROL in **DX12** mode and load into the game.
2. Run `ControlToolkitInjector.exe` from the extracted release folder. Keep `ControlToolkit.dll` beside the EXE.
3. Press **F10** to show or hide the toolkit.

Inject once per game session and use the same Windows elevation level as the game. The injector does not launch the game.
